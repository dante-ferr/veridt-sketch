# Veridt

## Arquitetura

Siga todas as regras arquiteturais do repositório de referência:

<https://github.com/RottyWheels/ESA_Trabalho>

A URL está em `docs/references/architecture-repo.txt`. As ADRs aceitas de lá são restrição deste código. O arquivo `docs/tecnologias.md` de lá é proposta, não ADR: não escolha linguagem nem framework sem decisão registrada no livro.

## Documentação

Registre no livro em `docs/` o que for importante para quem desenvolve e para agentes, no momento em que a aplicação muda. Seja o mais enxuto possível. O livro é a autoridade do método. O enunciado do produto fica no repositório de arquitetura apontado por `docs/references/architecture-repo.txt`. Não copie o enunciado para este repositório.

Pré-visualização local: `make docs-serve` em <http://localhost:3000>.

## Ritmo

Implemente uma ADR de cada vez. Na transição para a ADR seguinte, pare e pergunte antes de seguir.
